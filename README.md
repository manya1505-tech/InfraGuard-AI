# InfraGuard-AI
AI/ML-Based Predictive Maintenance System
**Tagline-"Predict Before Failure. Protect Before Damage."**

## Project Status
**InfraGuard AI – In Progress**

The machine learning model has been trained and evaluated using a real-world bridge dataset, achieving a Mean Absolute Error (MAE) of 3.78.
Backend development and frontend dashboard integration are currently underway.

## Upcoming Features

- Infrastructure health visualization
- AI-based risk analysis
- Alerts and warnings
- Preventive maintenance recommendations
